# Bundled Codex Remote Support

This directory contains the minimal runtime source used by Voice Relay to
connect to the signed-in Codex desktop application.

The files are bundled inside `Voice Relay.app` so a public installation does
not depend on a private checkout or a user-specific support path. Runtime state
is created under the current user's Application Support directory.
