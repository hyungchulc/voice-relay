# Authority Pack example

Copy this folder, edit the seven Markdown files, then select the copied folder
in `Voice Relay > Settings > Advanced > Authority Pack`.

Voice Relay reads only the seven files listed in
`Resources/authority-pack.json`. Keep credentials, tokens, private logs, and
unrelated personal data out of the pack because enabled contents are sent to
your Codex task with each substantive request.

The example is intentionally small. Add only stable guidance that should apply
across voice turns. Do not add scripts, commands that should run
automatically, URLs that should be fetched automatically, or instructions that
treat retrieved content and tool output as higher-priority authority.
