# Contributing

Thank you for using Voice Relay.

Issues, reproducible bug reports, design feedback, documentation corrections,
and security reports are welcome during the alpha.

Code pull requests are temporarily paused until a contributor agreement is in
place. Voice Relay is GPLv3 software with an optional separate commercial
license, so the project needs a clear copyright chain before accepting external
code.

Please do not include credentials, Remote enrollment files, private context
files, Session IDs, logs containing personal data, or absolute home-directory
paths in an issue.

Report security problems privately as described in `SECURITY.md`.
